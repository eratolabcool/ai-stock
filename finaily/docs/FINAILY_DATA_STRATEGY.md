# Finaily Data Strategy

## Positioning

Finaily is an AI investment intelligence platform, not a real-time market terminal.

The core assets are:

- Discovery Engine
- Policy Engine
- Theme Intelligence
- Company Research Database

## Data Flow

```
Research Engine
      |
      v
Intelligence Database
      |
      v
SEO Pages + User Tools
```

## Initial Approach

Avoid dependency on expensive market APIs during early product validation.

Focus on:

- AI company analysis
- Investment themes
- Research reports
- Portfolio intelligence

Real-time prices can be added later when user portfolio features require them.
